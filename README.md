## Projects

### Project 1: **Guess the Number 🎮**

**Description**  
A simple guessing game where you have to fix the range and follow these steps:

1. **Click on the "Start Game" button first** — the result will only be accurate if you start the game properly.
2. **Guess the number** and enter it in the given input box, then click on the **"Guess" button**.
   - If your guess is **too high** or **too low**, you'll get a hint.
   - If your guess is **correct**, you'll see the correct number along with the number of attempts you took.
3. To **restart the game**, click on the **"New Game" button** — it will reset everything.

> ⚠️ **Important:**  
Make sure you enter a **valid range and valid input** to continue playing.  
If there's any issue with the range or input, you'll get an alert message — correct it and try again.
